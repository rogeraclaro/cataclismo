# El Meu Theme

Un theme modern, net i responsive per WordPress.

## Característiques

- **Responsive Design**: S'adapta perfectament a mòbils, tablets i escriptoris
- **HTML5 & CSS3**: Codi modern i semàntic
- **Optimitzat per SEO**: Estructura adequada per motors de cerca
- **Compatible amb Gutenberg**: Suport complet per l'editor de blocs
- **Customizer**: Personalitza colors i opcions des del WordPress Customizer
- **Widget Ready**: Àrees de widgets a sidebar i footer
- **Menús de navegació**: Menú principal i footer configurables
- **Imatges destacades**: Suport per thumbnails en posts
- **Comentaris**: Sistema de comentaris integrat
- **Paginació**: Navegació entre articles i pàgines

## Instal·lació

1. Descarrega el theme i descomprimeix-lo
2. Puja la carpeta del theme a `/wp-content/themes/`
3. Activa el theme des de Aparença → Temes al WordPress admin
4. Configura els menús a Aparença → Menús
5. Afegeix widgets a Aparença → Widgets
6. Personalitza els colors a Aparença → Personalitzar

## Fitxers principals

- `style.css` - Full d'estils principal amb capçalera del theme
- `index.php` - Template principal per llistat d'articles
- `header.php` - Capçalera del lloc
- `footer.php` - Peu de pàgina
- `functions.php` - Funcionalitats i configuració del theme
- `single.php` - Template per articles individuals
- `page.php` - Template per pàgines estàtiques
- `search.php` - Template per resultats de cerca
- `404.php` - Pàgina d'error 404
- `sidebar.php` - Sidebar amb widgets

## Menús disponibles

1. **Menú Principal** - Navegació principal al header
2. **Menú Footer** - Enllaços al peu de pàgina

## Àrees de widgets

1. **Sidebar** - Barra lateral per widgets
2. **Footer 1** - Àrea de widgets al footer

## Personalització

El theme es pot personalitzar des de:
- **Aparença → Personalitzar**: Colors principals, logo, etc.
- **Aparença → Menús**: Configurar menús de navegació
- **Aparença → Widgets**: Afegir i configurar widgets
